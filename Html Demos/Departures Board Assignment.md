# Assignment: Build a Live Departures Board (Dynamic DOM with JavaScript)

**Topic:** Creating and updating the DOM with vanilla JavaScript
**Stack allowed:** HTML, CSS, and plain JavaScript only — **no frameworks, no libraries** (no React / jQuery / etc.)

---

## Scenario

Airports and train stations show a "departures board" that updates in real time as flights board, get delayed, or leave. None of those rows are written in the HTML — they are generated by JavaScript from live data. Your job is to build a working version of that board.

## Objective

Demonstrate that you can build an interface **entirely from data** by creating, filling, attaching, and updating DOM elements at runtime.

## Starter

You are given `index.html` with an empty board container:

```html
<div class="board" id="board"></div>
```

The board must start empty in the HTML. Every row must be created by your JavaScript.

---

## Core Requirements (must complete)

1. **Data model** — Store flights as an array of objects, each with: `time`, `flight`, `dest`, `gate`, `status`.
2. **Render from data** — Write a function that builds one row using `document.createElement`, sets text with `textContent`, and attaches it with `appendChild`. Loop over the array to render the whole board. *(Do not build rows with `innerHTML` string concatenation.)*
3. **Add Departure button** — Adds a new flight to the data and renders a new row dynamically.
4. **Reset button** — Restores the board to its starting state.
5. **Live clock** — A header clock that updates every second using `setInterval`.
6. **Live status updates** — Every few seconds, change one flight's status (e.g. `ON TIME → BOARDING → GATE CLOSED → DEPARTED`) and update only that cell in the DOM. Color the status by its value.
7. **Live counter** — Show a running summary, e.g. "7 departures · 2 boarding · 1 delayed".

## Constraints

- Separate files: `index.html`, `style.css`, `script.js`.
- DOM nodes must be built with `createElement` / `textContent` / `appendChild` (or `append`) — **not** `innerHTML`.
- Use event listeners (`addEventListener`), not inline `onclick` attributes.
- Code must be commented to explain each DOM step.

## Stretch Goals (optional, extra credit)

- A split-flap / flip CSS animation when a row appears or a status changes.
- Cap the board at N rows (remove the oldest when full).
- Sort flights by departure time.
- Persist the board to `localStorage` so it survives a refresh.
- Let the user type and submit a custom flight via a form.

## Deliverables

- The three source files (zipped) **or** a hosted link.
- A short README (½ page): what you built, how the DOM is created/updated, and any challenges.
